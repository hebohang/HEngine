# HEngine 1.1.0 公开发布

发布日期：2026-10-21。公开仓库：[hebohang/HEngine](https://github.com/hebohang/HEngine)。

本次将既有 1.1.0 Windows x64 SDK 原样发布到公开仓库，并同步源码和中英文平台说明；不重新构建 SDK，也不将源码中后续改动视为已经进入该二进制。

## 下载与使用

- 附件：`HEngine-1.1.0-Windows-x64.zip`，550,175,352 bytes。
- SHA-256：`fca5c1c51ac54ee4b8152bbada10cbb948ed702e975f422c8253efc065c5fde3`。
- 解压运行 `ProjectManager.exe`；新建项目或导入独立游戏的 `Project.heproject`。
- 包含 Windows Shipping / Development Player、Android ARM64 原生模板、Web / 微信 C# 导出工具，以及随包运行时、脚本 API 和 AI 开发文档。
- 本次没有 macOS 或 Windows ARM64 SDK 附件。macOS Apple Silicon 的 Editor / Game / `.app` 源码工作流见 [macOS 文档](../../Tools/macOS/README.md)。

## 来源与版本边界

公开仓库的源码快照来自 HEngineDev 提交 `fa5793da68d078daa94661b187fc0e608defbfaa`，另有公开发布文档调整。同步完整引擎、工具、模板及轻量示例；大型 `Examples/RenderingTests` 工程和素材不进入本次精简公开源码，仍保留于开发仓库。开发工作区的本机工程、缓存和未跟踪文件不属于本次公开源码。

SDK 原生引擎基线为 `745f6b61efc21e44da154899f00516ae123e44cb`；项目管理器更新来源为 `324653a14bad3dbedda05c2a674b3cc068fbb334`。这些是原开发仓库的提交标识，不是本公开仓库中的提交链接。公开 `v1.1.0` 源码归档包含当前同步源码，因此不等同于原 SDK 原生构建时的源码快照；需要追溯二进制时，以 SDK 内 `Docs/Release/RELEASE_PROVENANCE.json` 的逐组件来源和哈希为准。

保留 SDK 的原始字节和内嵌来源记录；其中的开发仓库链接、路径及历史验证日期不会因公开镜像而改变。普通 SDK 用户无需下载 GitHub 自动生成的 Source code 归档。

## 已有验证与限制

既有发布记录包含项目管理器创建/导入、空白与 SharedArena 项目打开、Windows C# Shipping 导出、Android APK 组装与签名、Web 浏览器交互、微信 Wasm/JS 构建检查，以及 SDK 布局、原生依赖闭包和架构检查。它们是原产物的历史验收，本次没有重新执行引擎构建或游戏运行测试。

Web / 微信采用便携渲染与项目适配，不承诺原生全部功能。最终 Android / 微信项目需要设备测试和自己的签名 / AppID；构建检查不是应用商店审核。Windows ARM64 的源码流程仍需相应构建和运行验收，不能从其他平台的 ARM64 推导支持。

本次发布检查：本地 ZIP CRC 与 SHA-256、原 Release 附件身份、公开源码快照一致性、README / 发布文档本地链接、Git 推送目标和上传后服务器大小 / SHA-256。验证回执保存在本次发布工作目录。
