# 衣物与角色接触

`AnimatorComponent` 提供可反射编辑、随场景保存的 `ClothPanels`、`ClothColliders`、`Feet`、`PelvisBone`、`LookAt`、`LimbTargets`。所有配置默认关闭，原角色维持原路径。

## 顶点布料

`ClothPanel.MaterialIndex` 绑定一个衣物材质槽；顶点颜色红通道为运动权重，0锁定动画表面，1允许移动 `MaxDistance` 米。布料材质忽略顶点颜色，避免权重图污染外观。拓扑边约束使用XPBD伸长compliance，相邻三角形的对角距离提供弯曲约束；每帧最多8个120Hz子步、1–24迭代。需清晰连续、相邻点间距大于两倍Thickness的低分辨率模拟网格。

每实例先恢复基础顶点并混合表情，再计算最终骨骼蒙皮位置，在世界空间模拟衣物，反变换回渲染顶点；重建法线/切线并提交当前/前帧位置。共享导入资产不会被修改。

`ClothCapsule` 在命名骨骼局部定义起终点和半径；身体碰撞优先于最大运动距离，避免不兼容约束让布料穿体。可选空间网格粒子自碰撞适用于少量主角衣物，不等于连续三角形布料自碰撞。固定顶点必须由资产作者放在身体之外。

超过0.25秒的时间跳变、超过2米的传送会重置；暂停不积分。`DeformationDistance`之外停止模拟并清理旧历史，恢复时重新初始化。不是GPU大规模布料或全衣物自动模拟。

## 接触与注视

`FootContact`为Upper/Lower/Foot命名骨骼，`SoleHeight`为脚踝到鞋底距离。静态非触发物体的物理射线获取脚下高度和邻近坡面；分析式两段IK保持骨段长度，站立接触可锁定世界位置，抬脚或超出可达窗口释放。`PelvisBone`平滑吸收有限向下高度差。已有`IsInAir`动画参数关闭空中接地，避免跳跃被强拉回地面。

`PlantHeight` 是鞋底到地面的接触过渡范围：在地面及以下保持接触修正，向上逐渐减弱，到范围之外保留原动画摆动。锁定的世界锚点与每帧混合后的 IK 目标分别保存，避免部分权重反复混合导致锚点漂移。旧实现仅用该阈值决定水平锁定，却仍把摆动脚拉向地面；完整步态验收发现此问题后已修复，具体运行复验状态见升级验收记录。

脚锁保持到真实摆动、失去有效地面或显式重置；不能用动画脚与锚点的距离判断可达性并瞬间重新落锚。不可达目标由两骨 IK 按真实骨长连续限制，不额外把目标切回远处动画脚。垂直高度始终在最终水平目标处采样并受 `MaxCorrection` 限制；最后一只脚离地时骨盆历史平滑归零，避免瞬间弹回。位置 IK 后恢复原动画脚掌朝向，再叠加坡面调整，避免膝踝旋转把前掌压入平地。这些机制不替代正确的动作与移动速度匹配。

`LimbConstraint` 的 `Upper`/`Lower` 定义两段求解关节，`End` 定义末端骨骼；`EffectorLocalOffset` 是该末端骨局部坐标中的真实接触点，例如末节指骨之外的指尖或手掌上的握持点。求解器旋转该点随附的整段骨链并保持骨段长度。默认零偏移维持旧资源的骨原点行为；偏移通过反射保存，不需要修改通用序列化器。

`TargetUUID` 与 `TargetOffset` 指定目标实体及其局部位置，未指定实体时使用 `WorldTarget`。目标偏移与末端接触偏移属于不同坐标系，不能互相替代。作者应通过 `inverse(actorWorld * endBoneModel) * contactWorld` 得到末端局部点，特别注意导入缩放；不要直接填入世界距离或未经转换的 FBX 厘米值。`Weight` 混合当前真实接触点与目标。

`WorldRotationDegrees` 为末端骨世界旋转的 XYZ 欧拉角（度，GLM quaternion Euler 约定，组合等价于 Rz * Ry * Rx），不是目标实体局部旋转。`RotationWeight` 默认为 0，保留旧位置约束；启用时旋转混合量为 `Weight * RotationWeight`（均限制到 0–1）。求解器先保留当前末端的 stretch/shear，并混合正交朝向，再由真实接触点减去旋转后的 `EffectorLocalOffset` 得到骨原点目标，执行世界空间两骨 IK，最后调整 End 子树朝向。角色旋转及非单位缩放参与完整坐标转换；不把局部偏移当成世界距离。超出骨链长度的目标仍按可达范围限制，不拉伸骨段，因此不能保证不可达目标同时满足接触位置。非有限参数拒绝且不写回姿态。此功能只规定手腕/末端朝向，不自动制作握持手型或解决手指碰撞；需选择正确 End 骨并实机检查手指与目标的可见接触。

`BoneLookAt`通过世界目标、局部朝前轴、最大转角和权重控制命名骨骼，先声明头部再声明眼球。Sequence可编排目标与权重；没有硬编码特定角色骨名。

代表资源与运行结果以升级验收记录为准；这些能力不能单凭编译通过判定最终动作或美术达标。
