# TAA history gather A/B

`Rendering.AntiAliasing.TaaOptimizedHistoryGather` defaults to `false`. The existing reference gather and an optional guide-first gather coexist in `SceneTaa.hlsl`. The flag uses the former padding word in the 48-byte C++/HLSL push-constant layout. The stable setting is included in serialization and the existing AA settings transaction; changing it requests temporal-history reset for a clean comparison.

The optimized path validates all 16 Catmull-Rom guide taps first and selects the closest valid tap using the same loop order, strict distance comparison and clamped coordinates. If every tap is valid, it reads all 16 colors and performs the original accumulation in the original order, including negative weights and the small-denominator fallback. If only some taps are valid, the reference ultimately discards its filtered sum and chooses the closest valid color; the optimized path directly loads that one color. If none is valid, both reject history. Surface history length comes from the same `NormalLength` load already used by guide validation; background history needs one separate length load at the selected pixel.

For a partially valid footprint containing V valid taps, history-color texture-load instructions decrease from V to 1, where V is 1–15. Fully valid footprints still read 16 colors. Cached surface history length also removes repeated `.w` reads when the nearest candidate changes. These are shader-load counts, not measured DRAM traffic or a promised frame-time improvement: texture caching, control flow, register pressure and scene coverage can change the benefit. No current-frame tile cache, reduced tap count, lower resolution or altered rejection threshold is included.

Validation must compare both flag values with the same shader binary, resolution, TAA/GI settings, camera path, scene, frame sequence and warmup. Cover fully valid history, mixed-validity silhouettes, disocclusion, all-invalid history, triangle/object identity boundaries, double-sided and Mask surfaces, moving bones, viewport edges/corners (including UV exactly 1), resize/camera cuts and reload. Preserve nearest-tap tie behavior, NaN sanitization, reset semantics and the GI reactive/history rules. Compare motion sequences and image differences, then measure the `SceneTAA` pass and whole-frame GPU span independently. The default remains the reference until those results are recorded.
