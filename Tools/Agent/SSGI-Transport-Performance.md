### 统计与资源边界

GI exclusive 是 trace、demod、temporal、spatial、upsample、remod、composite 的逐样本 timer 求和分类，不是经因果隔离的增量；不可加到 Frame，也不可相加各 pass P95。Off/On 整帧差包含共享资源与其他 pass 状态变化。共享深度/guide 的计时不自动全部归为新增 SSGI 成本。

动态三预设的实际最终运行日志均为8 rays，固定tick运动证据通过；主 CSV 没有逐帧 rays 字段，因此不声称597个样本逐一验证为8。静态日志 Low/Medium/High 分别2/2/4。

方差预滤与历史/预算调整没有通过这些CSV单独测得新增 radiance buffer；On−Off 的池和进程显存差含整条既有GI链，不能称为“本轮新缓冲字节”。默认1×1 normal fallback有效payload由4→8 bytes，GPU真实分配对齐成本未隔离。原始GI/SVGF历史等资源的完整逐资源驻留字节表未由本批计时导出。

### 方差预滤的独立成本 A/B

证据为 `variance-cost/analysis.json`：1920×1080 Low2，按 enabled/disabled/enabled/disabled 交错，仅改变3×3方差预滤分支开关，有效场景/曝光/设置一致。每run597个GPU样本；下表 mean/P95 单位ms，A-trous求和仅报告均值，未相加各pass的P95。

| run | ATrous[0] mean/P95 | ATrous[1] mean/P95 | 两级 A-trous mean 和 | Spatial 分类 mean/P95 |
| --- | ---: | ---: | ---: | ---: |
| 1-enabled-game-pbr-composite | 0.513/0.512 | 0.545/0.545 | 1.058 | 1.119/1.449 |
| 2-disabled-game-pbr-composite | 0.380/0.377 | 0.411/0.406 | 0.791 | 0.850/1.039 |
| 3-enabled-game-pbr-composite | 0.513/0.506 | 0.545/0.539 | 1.058 | 1.119/1.444 |
| 4-disabled-game-pbr-composite | 0.387/0.377 | 0.408/0.405 | 0.795 | 0.854/1.043 |

第1对 enabled−disabled：A-trous 两级合计 **0.26717 ms**，Spatial 分类差 0.26860 ms。

第2对 enabled−disabled：A-trous 两级合计 **0.26390 ms**，Spatial 分类差 0.26476 ms。

归因应采用A-trous pass差；整帧同时包含其他pass、调度与频率变化，不能用整帧差冒充本机制成本。`restoration.json` 中恢复hash与accepted的 `RtgiSvgf.hlsl` hash精确一致。此机制成本只覆盖本场景/1080p/Low2，不外推为所有档位固定开销。

这些是最终代码的专用性能证据，不单独构成画质验收。
